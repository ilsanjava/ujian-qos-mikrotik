Portal Ujian MikroTik QoS (XII TKJ 1 - 5)

Ujian Esei HOTS MikroTik QoS

Materi: Bandwidth Management, Queue Types, & Optimization

1. Analisis Dampak Indikator QoS pada Aplikasi Real-Time vs TCP File Transfer
Studi Kasus: Sebuah lab sekolah mengalami gangguan saat ujian voice/video conference (VoIP) karena audio putus-putus, sementara siswa lain mengunduh file ISO berbasis TCP secara bebas.
2. Evaluasi Kalkulasi Perilaku Fitur Burst pada Router MikroTik
Studi Kasus: Konfigurasi Simple Queue: Max-Limit = 8 Mbps, Burst-Limit = 20 Mbps, Burst-Threshold = 10 Mbps, Burst-Time = 8 detik.
3. Troubleshooting Fitur Burst / Token Bucket pada Saturated Link
Studi Kasus: Pelanggan mengeluh fitur Burst/Token Bucket tidak pernah memberikan alokasi di atas Max-Limit saat total link dari ISP terpakai 100%.
4. Perancangan Arsitektur QoS Perusahaan Menggunakan Queue Tree & Mangle
Studi Kasus: Kebutuhan pembagian bandwidth dinamis berprioritas tinggi untuk 3 divisi kantor (Eksekutif, Keuangan, Staf).
5. Troubleshooting Buffer Bloat & Konsumsi Resource (PFIFO vs BFIFO)
Studi Kasus: Router ber-CPU rendah mengalami pingsan (lag parah) saat Queue Size buffer dinaikkan ke 1000 pada FIFO.
6. Evaluasi Queue Type RED (Random Early Detect) pada Trafik Game Online
Studi Kasus: Game Center mengubah Queue Type ke RED, menyebabkan pemain game mengalami disconnect massal dan lag spike.
7. Troubleshooting Masalah Starvation pada SFQ Akibat Aplikasi Torrent
Studi Kasus: Lab sekolah menggunakan SFQ. Saat ada 1 pengguna menjalankan Torrent, pengguna lain mengalami starvation (tidak bisa browsing).
8. Koreksi Kesalahan Konfigurasi Classifier PCQ Upload vs Download
Studi Kasus: Siswa mengatur Classifier Src-Address untuk Download dan Dst-Address untuk Upload sehingga pembagian bandwidth menjadi kacau.
9. Kalkulasi & Troubleshooting Total Limit PCQ Skala Besar
Studi Kasus: Gedung dengan 200 client menggunakan PCQ (Limit Sub-Queue = 50 packet), namun Total Limit dibiarkan default 2000 packet.
10. Analisis Miskonsepsi Target Subnet /24 Simple Queue vs PCQ Rate
Studi Kasus: Admin mengisi Target = 192.168.10.0/24 Max-Limit = 10 Mbps di Simple Queue dengan harapan tiap siswa mendapat 10 Mbps.
